# Guma One logo integration

This update copies verified uploaded logos into canonical filenames under `public/logos` and maps those logos to app entries. Development-stage app rows now link to `/apps/:key` teaser pages.

REKTAFuel is registered as an in-development app using the supplied REKTAFuel logo. FuelDirect is no longer a separate portfolio entry. GUMALO uses its existing fallback until approved artwork is supplied.

The teaser form opens a prefilled email to `hello@guma.one`; confirm that address before deployment. It is not a persistent waitlist. Configure a secure backend with consent logging and privacy notice before claiming signups are stored.
